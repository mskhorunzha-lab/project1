# Project 3 — доработанный портал инфраструктуры

Эта папка фиксирует результат доработки проекта по итогам технического анализа.
Исходное Next.js-приложение оставлено в корне репозитория, чтобы не ломать сборку,
скрипты и деплой. Реализованные изменения доступны в коде проекта и покрыты CI.

## Реализовано

- RBAC-проверки для mutation API.
- Запись критичных действий в `AuditLog`.
- Zod-валидация входных данных API.
- Безопасная генерация задач ТО через `POST`, без side-effect `GET`.
- Проверка: ТО ИБП/СКУД нельзя закрыть без завершенного чек-листа.
- Генерация номеров работ через PostgreSQL advisory lock.
- Транзакционная складская операция с повторной проверкой остатка внутри транзакции.
- Замена уязвимого `xlsx` на XLSX-импорт через `read-excel-file`.
- Ограничение импорта: 5 МБ и 5000 строк.
- Отображение ошибок импорта и смены статуса в UI.
- Unit-тесты для генерации номеров и складских правил.
- GitHub Actions CI: Prisma validate, typecheck, lint, tests, build.
- Обновленная документация в корневом `README.md`.

## Проверка

```bash
npm ci
npm run typecheck
npm run lint
npm test
npm run build
npm audit --omit=dev --audit-level=high
```

High/critical production-уязвимости отсутствуют. Полный `npm audit --omit=dev`
показывает остаточные moderate advisories в транзитивном PostCSS внутри Next.js;
автоматический `npm audit fix --force` предлагает некорректный downgrade Next.js,
поэтому этот риск оставлен для обновления после безопасного upstream-исправления.
